# Mitmachen

1. Issue anlegen oder ein bestehendes kommentieren.
2. Fork/Branch erstellen, Änderung machen.
3. Lokal prüfen:
   - Plugin: `cd plugin && ./gradlew build` (Java 21)
   - Web: `cd web && npm ci && npm start` (Node 22, braucht eine MariaDB/MySQL)
4. Pull Request mit ausgefülltem Template öffnen.

Code-Stil: dem umgebenden Code folgen, keine unnötigen Abhängigkeiten.
Mit einem Beitrag stimmst du zu, dass er unter der MIT-Lizenz (siehe `LICENSE`) veröffentlicht wird.
